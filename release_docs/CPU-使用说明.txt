墨捕 OCR 1.1.0 · CPU 版

运行方法
1. 双击“墨捕OCR-CPU版.exe”。
2. 截图识别：点击“截图识别”，或按默认快捷键 Ctrl+Shift+A，再拖动鼠标框选文字。
3. 图片识别：点击“图片识别…”，选择 PNG、JPG、BMP、WebP 或 TIFF 图片。
4. Esc 或鼠标右键可取消截图。

本版本特点
- 已内置 Python、CPU 推理引擎和离线 OCR 模型。
- 无需安装 Python，无需连接云端 OCR API，断网也能识别。
- 适合没有 NVIDIA 显卡的 Windows 10/11 64 位电脑。
- 第一次识别需要加载本地模型，通常会比后续识别稍慢。

重要提示
- 请保留整个文件夹，不要只复制 EXE；“_internal”目录是程序运行所需文件。
- 如默认快捷键已被其他软件占用，可在软件中点击“快捷键…”修改。
- Windows 首次运行可能显示安全提示，请确认文件来源后再运行。

OCR 引擎：RapidOCR + ONNX Runtime（全程本地离线）
