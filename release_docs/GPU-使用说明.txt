墨捕 OCR 1.1.0 · NVIDIA GPU 版

运行方法
1. 双击“墨捕OCR-NVIDIA-GPU版.exe”。
2. 截图识别：点击“截图识别”，或按默认快捷键 Ctrl+Shift+A，再拖动鼠标框选文字。
3. 图片识别：点击“图片识别…”，选择 PNG、JPG、BMP、WebP 或 TIFF 图片。
4. 在“推理设备”中可选择 CPU 或 NVIDIA GPU（CUDA）。

本版本特点
- 已内置 Python、CUDA/cuDNN 运行组件和离线 OCR 模型。
- 无需安装 Python 或 CUDA Toolkit，无需连接云端 OCR API。
- 需要兼容的 NVIDIA 显卡和正常安装的 NVIDIA 官方驱动。
- 没有可用 NVIDIA 显卡时不会显示 GPU 选择项，仍可使用 CPU。
- GPU 初始化失败时，本次识别会自动回退到 CPU。

重要提示
- 请保留整个文件夹，不要只复制 EXE；“_internal”目录是程序运行所需文件。
- 如默认快捷键已被其他软件占用，可在软件中点击“快捷键…”修改。
- Windows 首次运行可能显示安全提示，请确认文件来源后再运行。

OCR 引擎：RapidOCR + ONNX Runtime CUDA（全程本地离线）
